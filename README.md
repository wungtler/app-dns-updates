# App DNS 일반판 테스트 배포

이 저장소에는 일반판 APK·업데이트 정보·변경점만 공개합니다. 소스, 개발판 APK, 서명 키, 관리자 도구 및 진단 기록은 포함하지 않습니다.

## 설치와 업데이트

별도 앱 사용 인증은 없습니다. Releases의 일반판 APK를 처음 설치한 뒤 앱 안에서 후속 업데이트를 받을 수 있습니다. 앱이 다운로드·패키지/버전/서명/SHA-256을 확인하고 Android 설치 확인 화면으로 연결합니다. 설치 허용과 최종 설치 승인은 사용자가 진행합니다.

일반판은 앱 화면을 열 때 새 버전을 확인합니다. 필수 업데이트를 확인하면 기존 VPN을 종료하고, 설치 완료 전까지 재시작을 제한합니다. 백그라운드에서 업데이트 확인을 예약하거나 창을 띄우지 않습니다. 설치 후 VPN은 직접 다시 켜주세요.

## 테스트 종료 정책

**현재 테스트는 진행 중입니다.** 최종 테스트 버전은 `2.9.99`로 예약했습니다. 향후 배포자의 명시적인 테스트 종료 공지를 앱이 확인하면 DNS/TLS 기능이 종료되고 정식 서비스 안내가 표시됩니다. 종료 APK의 설치에 실패해도 확인한 종료 상태는 유지됩니다.

통신 장애로 아직 업데이트/종료 공지를 받지 못했다면 기존 기능을 사용할 수 있습니다. 이미 확인한 필수 업데이트·종료 상태는 오프라인에서도 유지됩니다. 이 기능이 없는 과거 APK, 앱을 열지 않는 사용, 데이터 초기화/변조까지 통제하는 인증 서비스는 아닙니다.

## 검증 및 개인정보

선택 앱 DNS는 지정한 앱 UID의 DNS 요청에 적용합니다. Google Play 서비스 같은 공유 서비스를 따로 선택하면 다른 앱의 해당 서비스 요청에도 영향을 줄 수 있으며 자동 포함하지 않습니다. 모든 광고 차단은 보장하지 않습니다. TLS(SNI) 기능은 유지하며 2.6.0 단계에서 별도 검증합니다. 업데이트 확인·다운로드 시 GitHub 등 배포 서버에 IP와 요청 정보가 전달되며 피드백 기록은 자동 전송하지 않습니다. 실기기 업데이트/설치 통합 시험은 사용자 확인이 필요합니다.
